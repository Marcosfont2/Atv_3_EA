# Trabalho de Estruturas Algébricas – Teoria das Categorias em C++

Este projeto implementa conceitos fundamentais da **Teoria das Categorias** na categoria **Set**, utilizando a linguagem **C++**, como parte da atividade da disciplina **DIM0167 – Estruturas Algébricas**.

Foram implementados produtos, coprodutos, morfismos e traduções categóricas, respeitando a definição formal dos conceitos e garantindo ausência de efeitos colaterais nos morfismos.

---

## 📘 Conteúdo do Trabalho

O projeto contempla a implementação das seguintes questões:

### ✔ Questão 1
- Par ordenado (produto categórico)
- União disjunta (coproduto)
- Morfismos entre produtos
- Morfismos entre uniões disjuntas

### ✔ Questão 2
- Interface genérica de categoria
- Derivação automática do produto categórico
- Projeções canônicas do produto

### ✔ Questão 3
- Derivação automática do coproduto categórico
- Injeções canônicas do coproduto

### ✔ Questão 4
- Tradução de um morfismo entre produtos
- Decomposição do morfismo nas projeções canônicas

### ✔ Questão 5
- Implementação de um morfismo `Int × Char → Int × Char`
- Uso de pseudo-aleatoriedade de forma **pura e determinística**
- Eliminação de efeitos colaterais para garantir que a função seja um morfismo válido

## 🛠️ Requisitos

- Compilador **g++** compatível com **C++11** ou mais recente
- Sistema operacional: Windows, Linux ou macOS

---

## ▶️ Como Compilar

A partir da **pasta raiz do projeto**, execute:

```bash
g++ -std=c++11 src/main.cpp -o trabalho_EAC

```
Compile com:

```bash
./ trabalho_EAC
```
